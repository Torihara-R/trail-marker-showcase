# 写真を置く場所

README.md の、「📷 写真を貼る場所」のコメントに書いたファイル名で、ここに写真を置いてください。

| ファイル名 | 撮る画面 | README のどこか |
|---|---|---|
| `01-list.png` | 最初の画面（フォルダとマップの一覧。アイコンが付いていると見栄えがよい） | 冒頭 |
| `02-edit.png` | マップの「編集」（絵文字と矢印を置いたところ） | 「書き込み」 |
| `03-note.png` | 「表示」で、メモの吹き出しを開いたところ | 「書き込み」 |
| `04-dark.png` | デザイン設定（暗い背景にして、ボタンの色を変えたところ） | 「デザインと入れ子」 |
| `05-combo.png` | 2枚を並べた「組み合わせ」の表示 | 「デザインと入れ子」 |

置いたら、README.md の、そのコメントの「`<!--`」と「`-->`」を外して、画像の行を、表示させます。

撮るときの注意:
- 見本のマップ（アプリの「見本のマップを入れる」で入る地図）だけを使う。ゲームの画面や名前は、写さない。
- 個人情報（通知、名前など）が写り込まないようにする。
